---
title: "Pay a Winner"
description: "How the bounty creator pays each winner they pick."
icon: "hand-holding"
---

Winners don't claim a bounty. The creator picks each winner and pays them from the bounty.

<Steps>
  <Step title="Open the bounty">
    Open the bounty from **Bounties** with the wallet that created it.
  </Step>
  <Step title="Enter the winner">
    Paste the winner's address and a link or note about the winning work. FlowGuard turns it into a proof code and records only that code with the payment.
  </Step>
  <Step title="Pay">
    Choose **Pay winner**. The app calls `POST /api/bounties/:id/claim` with `winnerAddress`, `proofHash` and `signerAddress`. FlowGuard's server approves the payout, you approve it in your wallet, and `POST /api/bounties/:id/confirm-claim` records it. The network fee comes from the contract.
  </Step>
</Steps>

Each winner gets the prize per winner, and the contract stops paying once every prize is paid. Under **Manage** you can pause the bounty, resume it or cancel it. Cancelling returns the prize money that hasn't been paid to your wallet.
