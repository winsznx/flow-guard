---
title: "Create a Reward Program"
description: "Lock a reward budget and fund it from your wallet."
icon: "gift"
---

<Steps>
  <Step title="About the program">
    Go to **Rewards → Create a reward program**. Add a title, a description and a type. The type only labels and filters your programs.
  </Step>
  <Step title="Budget">
    Pick BCH or a token, then set the total budget and the limit per reward. To pay in a token, use the wallet with permission to create that token. No single reward can be larger than the limit.
  </Step>
  <Step title="Dates">
    You can send rewards from the start date. The end date is optional.
  </Step>
  <Step title="Create and fund">
    The app calls `POST /api/rewards/create`, then `GET /api/rewards/:id/funding-info` returns the funding `wcTransaction`. Approve it in your wallet, and `POST /api/rewards/:id/confirm-funding` marks the program `ACTIVE`.
  </Step>
</Steps>

See [Send Rewards](/guides/rewards/issue) for sending rewards from the program.
