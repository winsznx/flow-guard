The creator releases milestones in order, one at a time, when the work is done.

<Steps>
  <Step title="Open the grant">
    Open the grant with the wallet that created it.
  </Step>
  <Step title="Release">
    Choose **Release**. The app calls `POST /api/grants/:id/release`, FlowGuard's server approves it, and you approve it in your wallet.
  </Step>
  <Step title="Confirm">
    `POST /api/grants/:id/confirm-release` records the release with its `milestoneNumber`. The milestone amount goes to the recipient, and the network fee comes from the contract.
  </Step>
</Steps>

## Other controls

| Action | Route | Who |
| --- | --- | --- |
| Pause | `POST /api/grants/:id/pause` | Creator, if pausing was allowed |
| Resume | `POST /api/grants/:id/resume` | Creator |
| Cancel | `POST /api/grants/:id/cancel` | Creator, if cancelling was allowed |
| Change recipient | `POST /api/grants/:id/transfer` | Recipient, if the grant allows it |

Each one has a matching `confirm-*` route that takes the broadcast `txHash`. Cancelling keeps released milestones paid and returns the rest to the creator.
