A bounty holds prize money for a piece of work, like translating a guide or fixing a bug. You lock the full prize up front in a `BountyCovenant`, people send you their work outside FlowGuard, and you pay each winner you pick from the bounty. FlowGuard's server also approves each payment, so a bounty can never pay more winners or more money than you set.

## Creating a bounty

Go to **Bounties → Create a bounty** and fill in:

| Field | What it does |
| --- | --- |
| Title | What people see when you share the bounty |
| How to take part | What to do, how to send you the work, and how you pick winners |
| Pay winners in | BCH, or a token your wallet has permission to create |
| Prize per winner | Every winner gets this amount. It can't change later |
| Number of winners | How many prizes the bounty pays |
| Start and end date | You can pay winners from the start date. After the end date you can only cancel |

Then fund it from your wallet. Your wallet may need one setup step first, so you might approve two requests.

## Paying a winner

Open the bounty, paste the winner's address and a link or note about the winning work, and choose **Pay winner**. FlowGuard turns the link or note into a proof code and records only the code with the payment. The network fee comes from the contract.

## Pausing, resuming and cancelling

Under **Manage** you can pause the bounty, which stops payouts until you resume it. Cancelling sends the prize money that hasn't been paid back to your wallet. Winners already paid keep their prizes. Bounties created from November 2026 also return the unused fee BCH when cancelled.

See [Create a bounty](/guides/bounties/create) for the full guide.
