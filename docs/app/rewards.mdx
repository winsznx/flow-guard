A reward program is a fund for paying people for things they did, like referrals or contributions. You lock a total budget in a `RewardCovenant`, set a limit per reward, and send each reward from the program when someone earns it. Rewards arrive in people's wallets, so there's nothing for them to claim. FlowGuard's server also approves each reward.

## Creating a reward program

Go to **Rewards → Create a reward program** and fill in:

| Field | What it does |
| --- | --- |
| Title and description | Shown on the program's page |
| Type | A label for filtering your programs |
| Pay in | BCH, or a token your wallet has permission to create |
| Total budget | What you lock when you fund the program |
| Limit per reward | No single reward can be larger than this |
| Start and end date | You can send rewards from the start date until the end date |

## Sending a reward

Open the program, enter the person's address and the amount, and choose **Send**. The network fee comes from the contract.

## Pausing, resuming and cancelling

Under **Manage** you can pause the program, which stops rewards until you resume it. Cancelling sends what hasn't been sent back to your wallet. Programs created from November 2026 also return the unused fee BCH when cancelled.

See [Send rewards](/guides/rewards/issue) for the full guide.
