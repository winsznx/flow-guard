A grant pays a project in steps. You lock the full amount in a `GrantCovenant` when you fund it, split into milestones of the same size, and release each milestone when the work is done. FlowGuard's server also approves each release, and the contract counts how many milestones have gone out, so nobody can release more than you planned.

## Creating a grant

Go to **Grants → Create a grant** and fill in:

| Field | What it does |
| --- | --- |
| Name | Shown on the grant's page to you and the recipient |
| Recipient | The address that receives each milestone |
| Pay with | BCH, or a token your wallet has permission to create |
| Amount per milestone | Every milestone pays this amount. It can't change later |
| Milestones | Names and notes for each step. FlowGuard keeps these, and the contract only counts them |
| Pause and cancel | Whether you can pause or cancel later |
| Recipient can change their address | Whether the recipient can move the rest of the grant to a new address |

## Releasing a milestone

When a milestone is done, open the grant and choose **Release**. You approve it in your wallet, FlowGuard's server approves it, and the milestone goes to the recipient. The network fee comes from the contract.

## Pausing, resuming and cancelling

If you allowed it, you can pause the grant so nothing can be released, then resume it later. Cancelling ends the grant: released milestones stay paid and the rest comes back to your wallet.

See [Create a grant](/guides/grants/create) for the full guide.
